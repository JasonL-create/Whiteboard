# Whiteboard prototype v4
Static HTML/CSS/JavaScript prototype for the Northwoods office Whiteboard.

## Files to replace in GitHub
Replace all three app files for this version:
- `index.html`
- `styles.css`
- `app.js`

## v4 changes
- Listing workflow matches the current Whiteboard design: Listed, Approval Sent, Accepted, Lease Sent, Utility Form Sent, Signed Lease Received, Utility Form Received, Rent Paid, SD Paid, Remove LB, Key Pickup, Owner Notified.
- Removed Application Received.
- Listing cards show List Date, Days, and Lease Status.
- Turn cards can Create Listing & Archive Turn or Archive Turn.
- Listing cards can be archived.
- Archived filter stores removed processes and allows Restore to Whiteboard.
- Turn-to-Listing preserves the relationship and carries forward keys-return/listed information where available.
- Data remains in browser localStorage for prototype use.
